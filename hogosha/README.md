# 保護者向けページ（学級だより Web版）

公開URL（GitHub Pages）：`https://<ユーザー名>.github.io/<リポジトリ名>/hogosha/`

## できること
1. **配布物**：お手紙を画像付きで掲載。タップで拡大、複数枚はページ送り。
2. **提出物**：期限が近い順に「あと○日」で表示。3日以内はオレンジ、当日は赤。期限切れは自動で折りたたみ。
3. **お知らせ**：「重要」を付けると一番上に表示。

掲載日から7日間は自動で「NEW」が付きます。

## 更新のしかた（GitHubのWeb画面だけでOK）

### お手紙を載せる
1. お手紙をスマホで撮影 or PDFを画像（JPG/PNG）に変換
2. GitHubで `hogosha/images` を開き「Add file → Upload files」でアップロード
   - ファイル名は半角英数字に（例：`2026-10-06-kougai.jpg`）
3. `hogosha/data.js` を開いて鉛筆マークで編集し、`HANDOUTS` に追加：

```js
  {
    date: "2026-10-06",
    title: "校外学習のお知らせ",
    description: "参加票をご提出ください。",
    images: ["images/2026-10-06-kougai.jpg"],
    deadline: "2026-10-09",   // 提出があるときだけ
    submitWhat: "参加票",      // 提出するもの（省略可）
  },
```

`deadline` を書いたお手紙は、自動で「提出物」欄にも出ます（二重入力不要）。

### 提出物だけを載せる（お手紙なし）
`SUBMISSIONS` に `{ title, deadline, note }` を追加。

### お知らせを載せる
`NOTICES` に `{ date, title, body, important }` を追加。改行は `\n`。

### 注意
- 各項目の最後の `},` のカンマを忘れるとページが表示されなくなります。
- 保存（Commit changes）後、反映まで1〜2分かかります。
- 最後に `CLASS_INFO.updated` の日付も更新してください。

## ⚠️ 個人情報について
GitHub Pages は **URLを知っていれば誰でも見られる公開ページ** です（`noindex` で検索には出にくくしています）。
- 児童の氏名・顔写真・住所・電話番号が写ったお手紙は載せない
- 掲載前に学校（管理職）の許可を取る
