# ぴったり1（GAS Webアプリ版）

分数のタイルが上から落ちてくる、落ちものパズルです。**横1列の合計がぴったり1**になると、その列が消えます。
列の合計は画面に出ないので、自分でたし算（ちがう分母のときは通分）をして、どの列に置くかを決めます。
BACKLOG「11. 落ちものパズル×分数」として新しく作りました。見た目・動きは都道府県ポーカーと同じ水準にそろえています。

## ファイル

| ファイル | 中身 |
|---|---|
| index.html | 画面・ルール・タイルのデータがすべて入った1ファイル |
| Code.gs | ページを返すだけ（doGet） |
| appsscript.json | タイムゾーン Asia/Tokyo、V8、Webアプリの設定 |

データの保存先（スプレッドシートなど）は使いません。記録は各端末のブラウザ（localStorage）にだけ残ります。
外部への通信は Google Fonts（文字の形）だけです。画像は使わず、タイルはHTMLとCSSで描いています。

## あそびかた（3行で）

1. 落ちてくる分数のタイルを、**列をタップ**して動かし、**同じ列をもう一度タップ**（または ▼）で落とす。
2. 横1列の合計が**ぴったり1**で消えて点になる。**1をこえる**と、置いたタイルが「いし」になって場所をふさぐ。
3. ひとりは「決まった数のタイルで目標の列を消す」ステージを3つ（★3つでクリア）。ふたりは1台を交代で使い、同じ順番のタイルで点をくらべる（★3つ先取）。

## モード

| モード | 学年 | タイル（ステージ／レベル1・2・3） |
|---|---|---|
| 同じ分母 | 3・4年 | 1：分母4（1/4・2/4・3/4）／2：分母6（1/6〜5/6）／3：分母8（1/8〜7/8） |
| ちがう分母 | 5年 | 1：分母2・4（1/2・1/4・3/4）／2：分母2・3・6（1/2・1/3・2/3・1/6・5/6）／3：分母2・3・4・6（1/2・1/3・2/3・1/4・3/4・1/6・5/6＋約分前の2/4・2/6・3/6・4/6） |

- 同じ分母のモードは、1つのステージに1つの分母だけを使います。和は1までなので、仮分数・帯分数は出てきません。学習指導要領では、3年の「簡単な場合の分数のたし算（同じ分母・答えが1まで）」の範囲で遊べます（藤森さん確認：「3・4年」と表示）。
- ちがう分母のモードのステージ3には、約分する前の形（2/4・2/6・3/6・4/6）も少しまぜます（出る割合は約分した形の約3分の1）。「1/2 と 2/4 は同じ大きさ」に気づくきっかけにするためです。

## ルールと点

| できごと | 点 |
|---|---|
| 列を消す | その列のタイル1まいにつき **1点** |
| 分母が2しゅるい以上の列を消す（通分した） | **＋2点**（ちがう分母モードだけ） |
| ノーヒント（ヒントを使わずにステージクリア／ふたりは最後まで） | **＋5点** |
| いし（1をこえたタイル） | 0点（場所をふさぐ。その列が消えるといっしょに消える） |

### 1をこえたときの扱い

置いたタイルで列の合計が1をこえると、**そのタイルだけが「いし」**になります（値は0）。いしは場所をふさぎますが、その列ののこりのタイルで1になれば、いしもいっしょに消えます。
画面には理由を出します。例：`1/2 ＋ 3/4 ＝ 2/4 ＋ 3/4 ＝ 5/4　1より 1/4 大きい`

### 画面が先に教えないこと

- 列の合計（いまいくつか、あといくつで1か）は出しません。
- 置けるかどうか、こえるかどうかも、置く前には出しません。置いたあとに式で判定を見せます。
- 消えた列とこえた列の式は、ステージの結果画面にまとめて出ます（ふりかえり用）。

### ヒント（ものさし）

盤の右にある「ものさし」に、各列の合計の長さ（1に対してどのくらいか）が出ます。数字は出ません。
使うと、そのステージ（ふたりはその人の番）のノーヒントボーナス＋5点がなくなります。

### ひとりで（ステージ）

| ステージ | 消す列 | 使えるタイル（同じ分母） | 使えるタイル（ちがう分母） |
|---|---|---|---|
| 1 | 5列 | 18まい | 18まい |
| 2 | 6列 | 26まい | 26まい |
| 3 | 7列 | 36まい | 40まい |

- 目標の列を消すとステージクリアで★1つ。タイルがなくなる、または盤がいっぱいになるとやりなおし（★はへらない）。
- 3ステージクリア（★3つ）で「ぜんぶクリア」。3ステージの合計点を自己ベストとして記録します。

### ふたりで（1台を回す）

- レベル（1〜3）を選び、1人 **24まい** ずつ遊びます。**2人とも同じ順番でタイルが落ちてくる**ので、運の差がありません。
- 交代のたびに目かくし画面（「Bさんにわたしてね」）が出て、前の人の盤は見えません。
- 点の多いほうが★1つ。**同点なら、いしが少ないほう**。それも同じなら**早く置きおわったほう**（秒単位）の勝ち。それも同じなら引き分けで、★は次の回に持ちこし。先に★3つで優勝。先に遊ぶ人は回ごとに交代します。

### おちるはやさ

1マス落ちる時間：ステージ（レベル）1＝1.1秒、2＝0.95秒、3＝0.8秒。メニューの「ゆっくり」は1.5倍、「はやい」は0.7倍の時間。
落ちる途中で ▼ や同じ列のタップをすると、すぐに落ちます。

### 操作（タブレット縦・片手で遊べるように）

- **盤の列をタップ**：その列へ動く。**同じ列をもう一度タップ**：落とす。**下にスワイプ**：落とす。
- 盤の下の大きなボタン：◀（左へ）・▼おとす・▶（右へ）
- キーボード：← → で動かす、↓ かスペースで落とす、P でやすむ
- 「Ⅱ やすむ」で止まります。ほかのアプリに切りかえたときも自動で止まります。
- 動かす先の列（途中の列もふくむ）が、落ちているタイルより高く積まれていると、そこへは動けません。

### カードで覚える

| モード | カード | まい数 |
|---|---|---|
| 同じ分母 | 「□ ＋ ？ ＝ 1」の？（分母4・6・8） | 15まい |
| ちがう分母 | 1になる組み合わせ（例：1/2 ＋ 1/3 ＋ ？ ＝ 1 → 1/6）8まい、等しい分数（例：1/2 ＝ ？/4 ＝ ？/6）7まい | 15まい |

うらには通分した式（例：`1/2 ＋ 1/3 ＋ 1/6 ＝ 3/6 ＋ 2/6 ＋ 1/6 ＝ 6/6 ＝ 1`）が出ます。「おぼえた！」は記録され、メニューに「おぼえた ○/15まい」と出ます。

### はじめて遊ぶとき

最初の1回だけ「あそびかた」（5まい）が出ます。メニューの「？ あそびかた」でいつでも見直せます。

## 決めたこと（藤森さんに聞かずに決めた点と理由）

| 項目 | 決めたこと | 理由 |
|---|---|---|
| 盤の大きさ | 横5列×たて8段 | 1/6や1/8のタイルでも1にとどく（最大5まい）。幅400pxで1マス約65pxになり、指でタップしやすい |
| 1をこえたとき | 置いたタイルだけが「いし」になる | 理由の式を見せて、まちがいを場所の損で返す。列ぜんぶを消す罰にすると、ほかの正しいタイルまで損をする |
| タイルの出し方 | 「合計がぴったり1になる組」を2組ずつまぜて出す | 運だけで消せない列が続かないようにする。どの組も合計1であることを機械で確かめた |
| 消える条件 | 横1列の、いし以外のタイルの合計がちょうど1 | 列がいっぱいでなくても1になれば消える（1/2 ＋ 1/2 の2まいでも消える） |
| ひとりのクリア条件 | 「○まいのうちに△列」 | 上限がないと、でたらめに置いてもほぼ必ずクリアできた（下の検証）。上限があると計算した子だけがクリアしやすくなる |
| ふたりの同点 | いしの少なさ→かかった時間 | 分母4だけのレベル1では、ふつうに遊ぶと約6割が同点になった。★持ちこしだけでは勝負が長くなりすぎる |
| ふたりのタイル数 | 1人24まい | 1人2〜3分で終わり、交代しながら遊べる |

共通仕様から外したもの・置きかえたもの（藤森さん確認ずみ）：CPU戦→ひとりでステージ挑戦（★3つでクリア・自己ベスト記録）、配る／めくる動き→タイルが落ちる・列が光って消える・いしになる動き、「残すものを選ぶ」操作→置く列を選ぶ操作。ふたり対戦・★3つ先取・目かくし画面・チュートリアル・カードで覚えるはそのまま。

## 先生が調整できる値

index.html の `<script>` のいちばん上にある `CONFIG` にまとめています。

| 項目 | いまの値 | 意味 |
|---|---|---|
| cols / rows | 5 / 8 | 盤の横の列数・たての段数 |
| stageRows | 5 / 6 / 7 | ひとり：ステージで消す列の数 |
| stageTiles | 同じ分母 18 / 26 / 36、ちがう分母 18 / 26 / 40 | ひとり：ステージで使えるタイルの数 |
| pvpTiles | 24 | ふたり：1人が置くタイルの数 |
| tickMs | 1100 / 950 / 800 | 1マス落ちる時間（ミリ秒） |
| speedMul | ゆっくり1.5・ふつう1・はやい0.7 | おちるはやさの倍率 |
| ptPerTile / ptDiff / ptNoHint | 1 / 2 / 5 | 点 |
| winStars | 3 | ★いくつでクリア・優勝 |

タイルの種類は `CONFIG` のすぐ下の `SETS` で変えられます（分母は2・3・4・5・6・8のどれかにしてください）。

## 記録（この端末だけ）

ぜんぶクリアした回数と自己ベスト（モード別）、「おぼえた」カード、選んだモード・あそびかた・レベル・はやさ、チュートリアルを見たかどうかを保存します。
記録を消したいときは、ブラウザのサイトデータを消してください（「おぼえた」だけは「カードで覚える」の画面から消せます）。

## GASへの貼り付けとデプロイ

1. https://script.google.com で「新しいプロジェクト」を作る（名前は「ぴったり1」など）
2. `コード.gs` の中身を全部消して、**Code.gs** の中身を貼り付けて保存
3. 左の「ファイル」の「＋」→「HTML」で、名前を **index** にして追加。中身を全部消して **index.html** の中身を貼り付けて保存
4. （任意）「プロジェクトの設定」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック → 表示された appsscript.json に **appsscript.json** の中身を貼り付けて保存
5. 右上「デプロイ」→「新しいデプロイ」→ 歯車 →「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（学校のWorkspaceアカウントなら「（学校名）内の全員」にできます）
6. 「デプロイ」→ 許可を承認 → 表示された **ウェブアプリのURL**（…/exec）を児童に配る

### 更新するとき

index.html を貼りかえて保存 →「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」→「デプロイ」。URLは変わりません。

| モード・ステージ（タイル上限） | 得意 | ふつう | 苦手 | でたらめ |

| 同じ分母 S1（18まい） | 92% | 89% | 78% | 30% |
| 同じ分母 S2（26まい） | 99% | 97% | 86% | 27% |
| 同じ分母 S3（36まい） | 99% | 97% | 83% | 11% |

S1は入門なので、でたらめでも3〜4割クリアできます（運の要素）。S2・S3は計算しないとほぼクリアできません。

ふたりで（各2,000試合の1回戦、同じタイル順・24まい）：得意な子と苦手な子では、得意な子の勝ちが多い（例：ちがう分母レベル2で72%対18%）。ふつう同士で点もいしも同じになるのは、レベル1で約4〜6割、レベル2・3で約1〜2割。のこりは「早く置きおわったほう」で決まります（時間はシミュレーションでは数えていないので、自動プレイの引き分けは125回戦中10回＝8%）。

## 残った課題

- 実さいの子どもが、落ちる速さの中でどのくらい正しく計算できるかは、まだたしかめていません（上の割合は想定のモデル）。最初は「ゆっくり」で始めるのがおすすめです
- 学校のiPadの実機で、タップの反応と画面の高さ（下のボタンまで1画面に入るか）を確かめていません
- 効果音はありません

## トラブルシューティング

- **画面が真っ白**：index.html が最後（`</html>`）まで貼られているか確認
- **動きが少ない**：端末の「視差効果を減らす／動きを減らす」設定がオンだと、アニメーションを止めています
- **タイルが止まった**：「やすむ」になっていないか確認（ほかのアプリに切りかえると自動で止まります）
