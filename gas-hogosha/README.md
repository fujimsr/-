# 保護者向けページ（GAS版）

先生は **スプレッドシートに入力するだけ**。保護者は **URLを開くだけ**（ログイン不要）。

| ファイル | 役割 |
|---|---|
| `Code.gs` | サーバー側（シート読み込み・画像配信） |
| `index.html` | 保護者が見る画面 |
| `appsscript.json` | 設定（タイムゾーン・公開範囲） |

## できること
1. **配布物**：お手紙を画像付きで掲載。タップで拡大、複数枚はページ送り
2. **提出物**：期限が近い順に「あと○日」で表示。3日以内はオレンジ、当日は赤、期限切れは自動で折りたたみ
3. **お知らせ**：「重要」にチェックで先頭に固定
- 掲載日から7日間は自動で「NEW」
- **「公開」にチェックした行だけ表示** → 下書きして、管理職の確認後にチェック、という運用ができます

## 初回セットアップ（15分）
1. Googleドライブで新しいスプレッドシートを作る（例：「3年1組 学級だより」）
2. メニュー「拡張機能 → Apps Script」
3. `コード.gs` の中身を全部消して、`Code.gs` の中身を貼り付け
4. 左の「＋ → HTML」で `index` という名前のファイルを作り、`index.html` の中身を貼り付け
5. 上の関数選択で **`setup`** を選んで「実行」→ 権限を許可
   - スプレッドシートに「設定／配布物／提出物／お知らせ」シートができます
6. 「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
7. 表示されたURL（`https://script.google.com/macros/s/…/exec`）を保護者に配布（QRコードにしてお便りに載せると楽）

※ `appsscript.json` も反映したい場合は、Apps Script の「プロジェクトの設定 → 『appsscript.json』マニフェスト ファイルをエディタで表示する」をオンにして貼り付け。

## 毎回の更新
### お手紙を載せる
1. お手紙をスキャン or スマホで撮影し、**JPG/PNG** でドライブの任意のフォルダに保存
   - ファイルの共有設定は **変更不要**（非公開のままでOK。スクリプトが代わりに読み込みます）
2. ドライブでファイルを右クリック →「リンクをコピー」
3. 「配布物」シートに1行追加し、「画像」欄に貼り付け（複数枚はセル内改行 `Alt+Enter` で並べる）
4. 提出が必要なら「提出期限」「提出するもの」も入力 → **提出物欄にも自動で出ます**
5. 「公開」にチェック

### 提出物だけ・お知らせだけ
それぞれのシートに1行追加して「公開」にチェック。

### 反映のタイミング
シートを編集すると即反映されます。反映されない場合はメニュー「学級だより → ページにすぐ反映する」。
（コードを書き換えたときだけは「デプロイ → デプロイを管理 → 編集 → 新バージョン」が必要）

## 仕組みと安全面
- 保護者からはスプレッドシートもドライブも見えません。ページに出るのは「公開」チェックの行だけです
- 画像は「公開中の配布物に載っている画像」しか返さないようにしています（他のファイルIDを指定されても拒否）
- 画像はスマホ向けに縮小して送っています（通信量対策）

## ⚠️ 事前に確認が必要なこと
- **学校のGoogle Workspaceで「全員（匿名）」公開が許可されているか**
  管理者設定で外部公開が禁止されていると、手順6で「全員」が選べません。情報担当／教育委員会に確認してください。選べない場合は、個人アカウントではなく学校の運用ルールに沿った代替（学校HPの限定ページ等）を検討。
- **URLを知っていれば誰でも見られます**（検索には出にくいが鍵はない）
  児童の氏名・顔写真・住所が写ったお手紙は載せない。掲載ルールを管理職と決めてから運用。
